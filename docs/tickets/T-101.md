### A. 모델

### B. 목록이 만들어지는 시점

- [ ] 4B.2 단계 진입 시: 앞 단계 출력값(handoff)을 받아 그 노드의 AI가 세부 항목 제안 → 원자성 린터 → 틀 항목과 합치기(중복 제거) — 검증: 리플레이
- [ ] 4B.3 단계 확정(Lock) 규칙: 일반 모드 — 실행 시작 때 뼈대+1단계를 한 번 승인, 이후 단계는 "린터 통과 + 그 단계 산출물 범위 안"이면 자동 확정, 벗어나면 승인 카드 / 계획 모드 — 뼈대+1단계까지만 만들고 멈춤 / 오토 — 전부 자동 확정 — 검증: 모드별 테스트
