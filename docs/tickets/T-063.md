빌드 방법 (Windows):

- 저장소의 node_modules는 WSL(리눅스 pnpm)이 설치한 것이라 Windows 도구가 쓸 수 없다. 그래서 `apps/desktop/scripts/build-windows.ps1`이 apps/desktop과 이미 빌드된 apps/web/dist를 `C:\agentCli\harness-x-desktop-build`(별도 Windows 쪽 폴더)로 복사하고, 그 안에서 Windows pnpm으로 설치한 뒤 `pnpm --filter desktop tauri build`를 실행한다.
  1. WSL: `pnpm --filter web build`
  2. Windows: `powershell -ExecutionPolicy Bypass -File apps\desktop\scripts\build-windows.ps1 [-Test]` (`-Test`: 먼저 `cargo test`)
- 사이드카 서버: 기본은 `wsl.exe -d Ubuntu --cd /mnt/c/agentCli/harness-x -e bash -lc "source scripts/dev/env.sh && exec node packages/kernel/dist/cli.js serve --port 0 --no-watch --exit-with-stdin --token-file ~/.harness-x/run/desktop-token"`. 환경 변수 `HARNESS_X_REPO_WSL`, `HARNESS_X_WSL_DISTRO`, `HARNESS_X_SERVER_CMD`(JSON 배열)로 바꿀 수 있다. 토큰은 앱이 만들어 `HARNESS_X_TOKEN`(WSLENV)으로 넘기고, 웹뷰는 `invoke('server_info')`로 주소·토큰을 받는다. 서버는 Tauri 출처(http://tauri.localhost 등)만 CORS 허용.
- tauri build의 번들러가 WiX 3.14·NSIS 3.13을 GitHub에서 내려받아 `%LOCALAPPDATA%\tauri`에 캐시한다(처음 1회).
