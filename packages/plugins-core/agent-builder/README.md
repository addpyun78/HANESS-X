# agent-builder

에이전트 레지스트리·파이프라인 실행기·노드 계약(T-040~T-048)과 **대화로 에이전트 만들기**(T-100 Part 4)를 담은 하네스 플러그인.

## 말로 에이전트 만들기

하네스에 실제로 있는 자산(플러그인·스킬·엔진·도구·기존 에이전트)만으로 AI가 에이전트 초안을 조립해 줍니다.
AI는 **제안만** 하고, 저장은 **사람이 화면에서 버튼을 눌러야만** 됩니다.

### 1. 시작하기

1. 왼쪽 메뉴 **에이전트 만들기** → **말이나 글로 설명해서 만들기**를 누릅니다.
2. 왼쪽 서랍이 **💬 대화로 만들기** 탭으로 열립니다. (`블록` 탭으로 바꾸면 블록을 끌어다 직접 만들 수 있어요.)
3. 만들던 초안이 있으면 "만들던 초안이 있어요. 이어서 할까요?"가 먼저 보입니다. 아래 **만들던 초안** 목록에서 이어서 하거나 지울 수 있어요. 30일 지난 초안은 "필요 없으면 지워 주세요"라고 알려 줄 뿐, 저절로 지우지 않습니다.

### 2. 글로 설명하기

입력창에 원하는 에이전트를 적고 `Enter`로 보냅니다(`Shift+Enter` 줄바꿈, 한글 입력 중 Enter는 전송하지 않음).

```text
임장노트 화면 디자인을 검수해 주는 에이전트 만들어 줘. 고치는 건 codex로.
```

- 요청이 모호하면 AI가 **최대 3개**까지 선택지 버튼과 함께 되묻습니다(`builder.maxQuestions`). **알아서 해 줘**를 누르면 묻지 않고 바로 만듭니다.
- 설계에 쓰는 AI는 설정 `builder.engine`(비어 있으면 세션 기본 엔진)입니다. 설계 AI는 도구 없이 읽기 전용으로 한 번 실행돼요.

### 3. 말로 설명하기 (음성)

입력창 옆 **🎤**를 누르면 녹음, 다시 누르면 끝납니다. 바꾼 글은 **입력창에 채워지기만** 하고 저절로 보내지지 않으니, 고친 뒤 직접 보내세요.

- 설정 `stt.provider = local | browser | off` — `local`은 PC 안의 whisper.cpp, `browser`는 브라우저 음성 인식(처음에 "목소리가 브라우저 회사 서버로 전송될 수 있어요" 동의 필요).

### 4. 초안 보기

- 캔버스 위 띠 **"초안 v1 · 아직 저장 안 됨"**, 노드 테두리는 점선입니다. 노드는 0.2초 간격으로 차례로 나타나요(브라우저 저장소 `hx.builder.animation`을 `off`로 두면 꺼져요).
- 대화 패널의 **요약 카드**: 이 에이전트가 하는 일, 일을 맡을 AI 목록, 필요한 권한(예: "프로젝트 폴더 안의 파일을 고칠 수 있어요").
- 노드를 누르면 인스펙터에 **"AI가 이렇게 정한 이유"**가 보입니다.
- **빈 칸**(빨간 점선): 목록에 없는 기능입니다. AI가 새로 만들지 않아요. [도구 찾기](도구 고르기 카드) · [Forge로 만들기](Forge 입력창에 설명을 채워 둠, 보내기는 직접) · [이 칸 빼기] 중에서 고르세요.
- 인스펙터 아래 **저장 전 점검표**: 초안 모양 / 스킬·도구 / AI 로그인 / 권한 / 빈 칸.
- 인스펙터 **시험 실행** 탭은 초안 상태에서도 됩니다(결과는 저장되지 않음).

### 5. 고치기 — 캔버스로도, 말로도

- **캔버스**: 스킬 칩 끼우기·빼기, 엔진 블록 놓기, 노드 추가·삭제·연결이 그대로 됩니다. 고친 내용은 자동 보관돼요.
- **말로**: "검사는 claude로 바꿔줘"처럼 보내면 AI는 바꿀 부분(패치)만 돌려줍니다. 바뀐 노드·칩은 **노란색**으로 미리 보이고 대화 패널에 **바뀐 점** 목록이 뜹니다. [적용] 또는 [취소]를 누르세요.
  - 목록에 없는 것·로그인이 필요한 AI·되돌아가는 연결을 만드는 변경은 적용하지 않고 이유를 알려 줍니다.
  - 직접 고친 칸을 AI가 바꾸려 하면 "직접 고치신 부분을 바꾸려고 해요. 바꿀까요?"라고 묻습니다.
- **YAML 보기** 탭에서 고치고 [그래프에 적용]해도 됩니다.
- 적용할 때마다 v1, v2… 버전이 남습니다. 띠의 **버전 기록**에서 이전 버전을 보고 되돌릴 수 있어요(되돌리기도 새 버전으로 남음). `Ctrl+Z` / `Ctrl+Y`는 AI 패치 한 건을 한 단계로 되돌립니다.

### 6. 저장 — 사람만

1. 위쪽 **저장**을 누르면 확인 창이 뜹니다: 요약, 이름·부르는 말(`/이름`) 최종 수정 칸.
2. 빈 칸이 있으면 [빈 칸 채우고 저장하기(권장)] 또는 [빈 칸 있는 채로 저장 — 실행은 안 됨]을 고릅니다.
3. 이름이 겹치면 다른 이름(예: `design-review-2`)을 제안합니다.
4. 저장하면 `~/.harness-x/agents/<이름>/`에 `agent.yaml` · `pipeline.yaml` · `design-notes.md`(요청 원문·대화 요약·버전 기록)가 생기고, 곧바로 입력창 `/` 목록에 나타납니다.
5. 빈 칸이 남은 에이전트는 `/` 목록에 회색으로 보이고, 부르면 "빈 칸을 먼저 채워 주세요"라고 안내합니다.

저장 기록은 `~/.harness-x/agents-audit.jsonl`에 (시각, 저장한 사람, 초안 버전, 설계 엔진)으로 남습니다.

#### 왜 AI는 저장할 수 없나요?

- 엔진에 주는 도구 목록에 저장 도구(`agent.save`)가 없습니다.
- 저장 API `POST /api/agents/save`는 화면의 저장 버튼을 누를 때 받는 **1회용 클릭 토큰**(60초, `save-agent` 전용, 세션 토큰과 별개)이 있어야 동작합니다. 없거나·다시 쓰거나·시간이 지나면 403입니다.

### API (개발자용)

| 방법           | 경로                             | 하는 일                                                         |
| -------------- | -------------------------------- | --------------------------------------------------------------- |
| GET            | `/api/builder/inventory`         | 자산 전수조사 + 요약                                            |
| POST           | `/api/builder/design`            | `{request, skipQuestions?, answers?}` → 질문 또는 초안(v1 보관) |
| POST           | `/api/builder/edit`              | `{draft, instruction}` → 검사한 패치 미리보기 (적용 안 함)      |
| GET            | `/api/builder/drafts`            | 만들던 초안 목록                                                |
| GET·PUT·DELETE | `/api/builder/drafts/:id`        | 보기 · 자동 보관(`version: true`면 새 버전) · 삭제              |
| POST           | `/api/builder/drafts/:id/revert` | `{version}` 이전 버전으로 되돌리기                              |
| POST           | `/api/gesture-tokens`            | `{kind: "save-agent"}` 클릭 토큰 (화면이 버튼을 누를 때만)      |
| POST           | `/api/agents/save`               | `x-harness-gesture` 헤더 + `{draftId, draft, allowIncomplete?}` |

설정 (`~/.harness-x/settings.json`):

```json
{ "builder": { "engine": "claude-code", "maxQuestions": 3, "animation": true } }
```
